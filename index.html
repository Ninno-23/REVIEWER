Keep IndexedDB as your offline source of truth. If you run the included Python server, you can sync a backup between devices.

Use HTTPS and a strong token before exposing a sync server outside your own device/network.

Install & offline

The PWA shell works offline after the app shell and required local resources are cached. AI is allowed to be unavailable offline.
