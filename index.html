Settings & data

Manage the local StudyVault workspace.

Security

Use a PIN for a local browser lock. PBKDF2 with a random salt is used instead of storing the PIN itself.

Backup

Export all processed study data as JSON and restore it later. Original PDF binaries are not included.

Appearance

Switch between dark and light modes.

Application

The app can be installed as a PWA. Study data stays local. PDF.js handles PDFs and Tesseract.js handles optional photo OCR in the browser; no LLM, account, or paid API is required.
