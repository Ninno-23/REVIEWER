StudyVault / Carrot AI v154.0
=============================

1. Copy .env.example to .env and set OPENAI_API_KEY=your-key
2. Double-click START-CARROT-AI.bat (Windows) OR run: python server.py
3. Open index.html in your browser
4. Hard refresh (Ctrl+Shift+R)

Chat like ChatGPT:
- Type in "Message Carrot…"
- Reply actions: Copy · Read aloud · Regenerate · Shorter · Continue

Images: "create an image of …" or Create image button
Summaries: open PDF → "summarize"
Cards/Quiz: "turn this into flashcards" / "make a quiz from this"
Compare: import 2+ PDFs → "compare documents"

Full ChatGPT-class results need OPENAI_API_KEY + server running.
Without a key, local study tools still work (labeled offline).

See CARROT-AI-SETUP.md and README.md for details.
