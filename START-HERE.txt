STUDYVAULT v14 — START HERE

1. Open index.html in a browser, or publish this folder to GitHub Pages.
2. Add a PDF/photo. The reviewer, flashcards, quiz, notes, and search remain local.
3. AI: use the Instant Tutor first. Qwen is optional and can be loaded from Reviewer > Load AI.
4. Optional sync backend:
   Windows PowerShell:
     $env:STUDYVAULT_SYNC_TOKEN="use-a-long-random-token"
     python server.py
   macOS/Linux:
     STUDYVAULT_SYNC_TOKEN="use-a-long-random-token" python3 server.py
   Then enter http://127.0.0.1:8787 and the same token in Settings > Optional Sync Backend.
5. Do not expose server.py publicly without HTTPS and stronger authentication.

This release does not pretend that remote PDF.js/Tesseract model assets are bundled; they still need first-use network access unless the browser has already cached them.
