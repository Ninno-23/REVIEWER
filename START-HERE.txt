STUDYVAULT v19 — VISUAL OCR — START HERE

1. Open index.html in Chrome/Edge/Firefox, or publish this folder to GitHub Pages / any HTTPS static host.
2. Add a PDF or study photos. Reviewer, Cards, Quiz, Notes, Search stay local.
3. Scanned / picture PDFs: wait for “Reading pictures…” — OCR runs on sparse pages automatically.
4. On Reviewer → photos: Re-run OCR if needed; Create study pic downloads a local study card (photo + caption).
5. Tutor tab = responsive chat about your material (Instant works without downloading a model).
6. Settings → Check for updates reads version.json so you know if a newer shell is available.
7. Optional sync:
     STUDYVAULT_SYNC_TOKEN="$(openssl rand -hex 32)" python3 server.py
   Then enter http://127.0.0.1:8787 and the token in Settings.
8. Never expose server.py publicly without HTTPS and a strong token.

Your study data lives in this browser's IndexedDB. Export backups from Settings for family safety.

OCR / PDF engines need internet once so they can cache; after that the shell stays offline-friendly.
