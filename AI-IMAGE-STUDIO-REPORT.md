# Carrot AI Image Studio v153.0

- Cloud path: OpenAI Responses `image_generation` tool with the configured GPT image model.
- Compatibility path: `/v1/images/generations` for OpenAI-compatible gateways.
- Style auto-detection: photo / anime / diagram / poster / illustration / cinematic from the user’s words.
- Browser fallback: direct-image loading (no CORS requirement) via public Flux-enhanced engines.
- Offline fallback: StudyVault local study-image generator, explicitly labeled local.
- API keys are never placed in browser JavaScript.
- Higher default public resolution and cleaner prompt cleanup for free engines.
