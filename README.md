# StudyVault v7

Modern visual layer for the StudyVault local-first study app.

- `app.js` is intentionally unchanged from v6.
- `reviewer-engine.js` remains the advanced reviewer engine.
- `styles.css` is the new modern responsive visual system.
- `service-worker.js` caches the stylesheet as part of the PWA shell.

Upload the whole folder to GitHub Pages. Keep all files at the repository root.
