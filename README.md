# StudyVault v5

Local-first reviewer app for PDFs, screenshots, and class photos.

Features: PDF extraction, photo import, optional browser OCR with Tesseract.js, structured reviewer, definitions, key points, memory cues, exam checklist, study questions, page/photo search, 50-card flashcard generation, 20-item quizzes, rich notes with image insertion, IndexedDB storage, PBKDF2 PIN, backup/import, and PWA shell.

No LLM, account, backend, or paid API is required. Tesseract.js is OCR rather than a generative AI service. Photo OCR requires the Tesseract.js web assets to load; the photo itself can still be saved if OCR is unavailable.
